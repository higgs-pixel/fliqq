# Dependencies

Every third-party crate and why it is here. Crypto crates are limited to those named in
SPEC section 6.1.

## fliq_core

| Crate | Purpose | Spec reference |
|---|---|---|
| `snow` 0.9 | Noise protocol (`Noise_NKpsk0_25519_ChaChaPoly_BLAKE2s`) for every stream | 6.1 (required) |
| `blake3` | Chunk hashes and manifest hash | 6.1 (required) |
| `hkdf`, `sha2` | HKDF-SHA256: verification code, data token, PSK expansion | 6.1 (required) |
| `getrandom` 0.2 | OS CSPRNG for session id, PSK, port choice | 6.1 (required) |
| `zeroize` | Wipe keys, PSK, token on drop | 6.1 (required) |
| `ciborium` | CBOR for the QR payload and control messages | 5.1, 6.4 |
| `serde`, `serde_bytes` | (De)serialization of those messages | 5.1, 6.4 |
| `base64` | base64url for the `fliq://` URI | 5.1 |
| `socket2` | 4 MiB socket buffers, keepalive, random-port binding | 4.5, 7.2 |
| `crossbeam-channel` | Bounded queues between pipeline stages | 7.1 |
| `if-addrs` | Enumerate local IPv4 addresses for the QR | 4.4 |
| `fs4` | Free disk space before Accept | 6.6 |
| `thiserror` | Error type with codes and plain-language messages | 14 |
| `libc` | `statfs` for FAT32 detection (Linux/Android) | 7.3 |
| `windows-sys` 0.59 (Windows only) | `GetVolumeInformationW` for FAT32 detection | 7.3 |

Dev only: `proptest` (parser fuzzing), `tempfile` (test folders).

## fliq_cli

`fliq_core`, `blake3` (crypto-bench), `tempfile` (benchmark scratch folder). Argument parsing
is hand-written to avoid a dependency.

No analytics, logging or network crates. `cargo deny check` (config in `core/deny.toml`) runs
in CI to audit advisories and licenses.

## App (Flutter, M2)

| Package | Purpose |
|---|---|
| `flutter_rust_bridge` 2.11.1 (Dart + Rust) | The only channel between UI and Rust core: control calls and event streams (spec 3) |
| `qr_flutter` | Renders the pairing QR (white panel, onyx modules, level M) |
| `file_selector` (flutter.dev) | Native file and folder pickers on Windows |
| `path_provider` (flutter.dev) | App-support folder (settings, Transfer Logs) and Downloads folder |
| `path` (dart.dev) | Path joining |
| `flutter_lints` (dev) | Lints |
| Inter 4.1 font (SIL OFL 1.1, bundled in `assets/fonts`, license included) | UI and display type, no network fonts |
| Material outlined icons (Apache-2.0, part of Flutter) | One consistent icon set, no extra package |
| `rust_builder/` + `cargokit` (generated by flutter_rust_bridge, MIT/BSD) | Builds the Rust library during `flutter build` |

Build tools (not shipped): `flutter_rust_bridge_codegen`, `cargo-expand`, Inno Setup 6.
